# Good First Issues

Looking for something to work on? Here are some ideas for features that would be great contributions:

1. **Add dark mode**: Implement a toggle in the React frontend to switch between light and dark themes.
2. **Add file type icons**: Show different icons (e.g., PDF, image, document) next to the filename based on the `content_type` or file extension.
3. **Add file sorting**: Allow users to sort the document list by name, size, or upload date (ascending/descending).
4. **Add pagination**: If there are many documents, display them in pages instead of all at once.
5. **Add nested folders**: Update the backend and frontend to support folders inside other folders.
6. **Add file sharing**: Allow users to generate a public link to share a specific document.
8. **Add drag-and-drop upload**: Improve the UI to allow dragging files directly onto the page to upload them.
9. **Add file preview**: For images or PDFs, show a small preview thumbnail in the document list.
10. **Add file size formatting**: Format the raw bytes into a human-readable size like `1.5 MB` or `500 KB` in the frontend.
11. **Add favorites**: Allow users to "star" or "favorite" documents for quick access.
12. **Add recently uploaded section**: Show a list of the 5 most recently uploaded documents on the dashboard.

Choose an issue, open an issue ticket on GitHub to let others know you're working on it, and submit a PR!
