# Contributing to Document Management System

Thank you for your interest in contributing! This project is designed to be beginner-friendly.

## How to Contribute

1. **Fork the repository**: Click the "Fork" button at the top right of this page to create a copy in your own account.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/DocVault.git
   cd DocVault
   ```
3. **Create a branch**: Create a new branch for your feature or bugfix.
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make changes**: Implement your feature, fix the bug, or improve documentation.
5. **Test locally**: Ensure both backend and frontend start successfully and your changes work as expected.
6. **Commit changes**: Write clear, concise commit messages.
   ```bash
   git commit -m "Add dark mode support"
   ```
7. **Push the branch**:
   ```bash
   git push origin feature/your-feature-name
   ```
8. **Open a Pull Request**: Go to the original repository on GitHub and click "New Pull Request". Compare your branch against the `main` branch.

Please make sure your code is readable and keeps the project simple!
